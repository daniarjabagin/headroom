# Provider logos

Provider logos come from [Simple Icons](https://simpleicons.org) 16.32.0 (CC0-1.0), with a size and a
fill added. Each file is named after the provider id, so shells find it as `icons/<id>.svg`.

| file | Simple Icons slug |
| --- | --- |
| `codex.svg` | `openai` (via `assets/providers/openai.svg`) |
| `claude.svg` | `claude` |
| `cline.svg` | `cline` |
| `copilot.svg` | `githubcopilot` |
| `cursor.svg` | `cursor` |
| `kimi.svg` | `kimi` |
| `minimax.svg` | `minimax` |
| `ollama.svg` | `ollama` |
| `opencode.svg` | `opencode` |
| `openrouter.svg` | `openrouter` |
| `zai.svg` | `zdotai` |

The logos are trademarks of their owners (OpenAI, Anthropic, Cline, GitHub, Anysphere, Moonshot AI,
MiniMax, Ollama, SST, OpenRouter, Z.ai). Headroom uses them only to identify the service whose usage
is shown, and is not affiliated with or endorsed by any of them.

Claude keeps its brand color `#D97757`; every other logo is monochrome and follows the text color.
Providers without a Simple Icons logo (Grok, Devin, Antigravity) and any id without a file use
`provider-generic.svg`.

`headroom-symbolic.svg`, `flame-symbolic.svg` and `provider-generic.svg` are Headroom's own glyphs;
the first two are shared with the GNOME extension.
